# kinarm-stroke-uncertainty

Evidential deep learning with uncertainty-based refinement for stroke detection from Kinarm features, as published in:


F. Akbarifar, S. P. Dukelow, A. Jin, P. Mousavi and S. H. Scott, "Optimizing Stroke Detection Using Evidential Networks and Uncertainty-Based Refinement," in IEEE Transactions on Neural Systems and Rehabilitation Engineering, vol. 33, pp. 566-576, 2025, doi: 10.1109/TNSRE.2025.3531768.
